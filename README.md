#### Sistema de Mercado em Java ####

Sistema de gerenciamento de mercado desenvolvido em **Java**, executado através do terminal.

O projeto foi desenvolvido com o objetivo de praticar **Programação Orientada a Objetos (POO)**, estruturas de dados, métodos, classes e organização de um sistema baseado em situações reais.

---

###- Funcionalidades ###

Atualmente o sistema permite:

### Produtos ###

- Cadastrar produto
- Listar produtos
- Buscar produto
- Alterar produto
- Remover produto
- Controlar preço
- Controlar quantidade em estoque
- Controlar categoria

###  Clientes ###

- Cadastrar cliente
- Listar clientes
- Buscar cliente
- Alterar cliente
- Remover cliente
- Cadastro de CPF
- Cadastro de telefone

### 🛒 Vendas ###

- Criar uma nova venda
- Adicionar produtos à venda
- Definir quantidade
- Calcular subtotal
- Calcular valor total
- Finalizar venda
- Atualizar estoque após a venda

### Pagamento ###

O sistema possui suporte às principais formas de pagamento:

- Dinheiro
- PIX
- Débito
- Crédito

No pagamento em dinheiro, o sistema também realiza o cálculo do troco.
